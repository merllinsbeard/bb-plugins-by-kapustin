## Choose a specialist while writing

Select a role beside the message composer and send normally. The role applies in the same conversation, without creating another chat. Choose no role to return to the general assistant. Your composer model and permission choices stay in effect.

## Requirements

Install and enable Agent Roles first. No personal roles are included. This plugin uses a scoped content script around the BB message submission routes because SDK 0.4.87 has no submit middleware. Recheck compatibility after BB updates. Composer actions are hidden in compact mode.
