# Role Picker

Выбор роли слева от микрофона. Требуется включённый **Agent Roles**.

1. Выберите роль в меню.
2. Отправьте сообщение обычной кнопкой или Enter.

Специалист отвечает в **этом же треде**. В существующем треде роль применяется со следующего сообщения, в новом — с первого. Дополнительные чаты не создаются. «Без роли» снимает роль при следующей отправке.

Роль задаёт инструкции агента. Модель, провайдер, права и окружение остаются выбранными в BB. Файлы и @-упоминания проходят через обычную отправку. Удалённая роль или ошибка её подготовки блокирует отправку с обычным восстановлением черновика.

## Реализация

SDK 0.4.87 не имеет middleware обычной отправки. Full-trust content script перехватывает только same-origin POST `/api/v1/threads` и `/api/v1/threads/:id/send`, сопоставляя их с конкретным composer. Он добавляет `agent-only` инструкции, сохраняя весь исходный запрос. Для нового треда задаёт metadata Agent Roles при штатном создании; для существующего обновляет metadata перед отправкой. Это также позволяет применить роль к уже запущенной сессии без её перезапуска. Настройки роли, включая отдельную модель, не подменяют настройки composer.

При перезагрузке плагина wrapper и обработчики отключаются; черновой выбор роли до отправки сбрасывается. Сохранённая роль читается из metadata треда. При обновлении BB нужно перепроверить маршруты и wire schema. В компактном режиме SDK скрывает composer actions.

```sh
npm install --include=dev
npx tsc --noEmit
node --experimental-strip-types --test server.test.ts
bb plugin build .
bb plugin install . --yes
```
