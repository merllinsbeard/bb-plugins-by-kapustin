# Мои задачи

Личный чек-лист в BB с фоновой помощью агента.

- Компактная типографика: заголовок 18 px, разделы 14 px, текст задач 13 px.
- Все задачи без сроков и дат. Компактный общий список, сгруппированный по разделам с названиями и иконками; «Без раздела» и раскрываемая восстанавливаемая корзина.
- Разделы можно создавать, переименовывать, менять им иконки и удалять. При удалении раздела его задачи переходят в «Без раздела».
- Раздел задачи выбирается в её модальном окне. Новая задача добавляется прямо внутри нужного раздела. Выполненные задачи раскрываются отдельно в каждом разделе.
- Задача открывается в модальном окне по центру экрана.
- Заметки, шаги и вложенные подзадачи.
- Развить идею, разбить на шаги, помочь выполнить — для задачи или отдельного шага.
- Все три действия работают в фоне через ephemeral Codex exec: `gpt-6-astra`, low effort. Новые BB-треды не создаются.
- Очередь, результаты, ошибки и остановка отображаются внутри задачи. Окно можно закрывать во время работы.
- Предложения выбирает пользователь. Предложения подзадачи становятся её дочерними шагами.

Открыть: `/plugins/my-tasks/checklist`.

## Разработка

```sh
npm install --include=dev
npm run check
npm test
npm run build
bb plugin install . --yes
```

Для разработки установленного плагина: `bb plugin dev`.

## Проверка

Тесты используют официальный fake-host SDK и временный SQLite: параллельные записи, сохранность данных при reload, предложения, валидация, фоновые задания без тредов, область подзадачи, отмена и ошибки. Живой запуск проверен с Astra low.

## Данные и ограничения

Требуется авторизованный Codex на подключённой машине. Фоновая помощь готовит текстовые результаты и исследует доступные данные в режиме read-only; внешние изменения не выполняет. Прерванная перезапуском активная работа показывает ошибку и не повторяется автоматически; очередь сохраняется. Таймаут одной работы — 10 минут.

Данные хранятся в SQLite плагина. До 200 шагов в задаче; встроенный помощник возвращает до 30 предложений за запуск. Последние результаты сохраняются в задаче. Удаление задачи отменяет её фоновые работы. Удаление шага удаляет его потомков и отменяет их работы. Старые связанные чаты сохраняются как ссылки.

CLI `propose` заменяет корневые предложения, сохраняя предложения подзадач и принятые шаги. CLI `list` ограничен последними 100 задачами. Подробности: [skills/my-tasks/SKILL.md](skills/my-tasks/SKILL.md).
