---
name: goals
description: Read personal goals when the user asks to compare or align an answer, idea, decision or plan with their goals.
---
When the user requests alignment with their goals, run `bb goals show` to read the current active personal goals in priority order. Explain how the answer or proposal supports specific goals, where it conflicts and what adjustments would help. If no goals are saved, ask for them instead of inventing them.

These are the user's personal aspirations, not a task queue for agents. Do not routinely consult or apply them to unrelated requests. Do not start pursuing, edit or mark goals complete without the user's request. They are shared across projects and editable in the Goals sidebar. Existing sessions receive changed instructions when the provider session next starts.
