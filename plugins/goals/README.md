# Цели

Постоянные исходники плагина личных целей пользователя.

Вкладка **Цели** — единый компактный список в стиле «Мои задачи» для всех агентов и проектов. Добавляйте цели, редактируйте по клику в центральном модальном окне, меняйте приоритет перетягиванием или кнопками ↑/↓. Верхние строки важнее. Круглые чекбоксы, ввод новой цели внутри списка, заголовок 18 px и текст строк 13 px повторяют «Мои задачи». Выполненные цели находятся в раскрываемом блоке «Выполнено», но не передаются агентам. Каждое действие сохраняется автоматически с проверкой версии; при конфликте черновик остаётся в редакторе.

Прежние общие поля преобразуются в карточки без потери текста. Старые проектные записи сохраняются в базе, но не используются. До 30 карточек по 800 символов.

`bb goals show` читает личные цели, общие для всех проектов. Агенты обращаются к ним, когда пользователь просит сопоставить ответ, идею, решение или план со своими целями. Они объясняют соответствие, противоречия и возможные улучшения. Цели не являются заданиями агентам и не применяются автоматически к остальным запросам. Обновление инструкций зависит от следующего запуска сессии провайдера; уже работающие сессии не прерываются и не получают принудительных сообщений. Изменение целей не запускает работу автоматически.

Разработка: `npx tsc --noEmit`, `node --experimental-strip-types --test server.test.ts`, `bb plugin build .`, `bb plugin reload goals`.
